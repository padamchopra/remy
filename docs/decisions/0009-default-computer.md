# D9: Default to a hosted computer, then apply routing rules

## Decision

A new org's first thread runs on a Remy computer. Ordered rules by team, workspace, and computer choose later work, with a composer override.

## Consequences

An org is useful before it connects a Mac. The resolver must explain and dry-run its choice.

## Rejected alternatives

- Requiring a personal computer before the first thread.
- A single org-wide computer selection, because different workspaces need different capabilities.
- Hidden automatic routing with no override or explanation.
