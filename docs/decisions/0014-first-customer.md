# D14: Build first for mid-size engineering organisations

## Decision

The first customer is a mid-size engineering org. SSO, an audit log, security hardening, and procurement-ready answers are launch requirements.

## Consequences

Launch is measured by a stranger completing the full SSO-to-pull-request path without direct support.

## Rejected alternatives

- Optimising launch for individuals or very small teams, because local Remy already serves them.
- Treating SSO, audit, or procurement work as post-launch enterprise add-ons.
