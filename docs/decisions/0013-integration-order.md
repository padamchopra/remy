# D13: Build GitHub, then Linear, then Slack

## Decision

Connections land in the order GitHub, Linear, then Slack.

## Consequences

Linear-synced boards and routines establish open-by-default threads before Slack starts or mirrors them.

## Rejected alternatives

- Slack before Linear, because it would arrive before joinable automated threads and board mapping are proven.
- Linear before GitHub, because hosted computers need repository access and member-authored pull requests first.
- Building all integrations independently before a shared connections framework.
